# mini-RAG

A mini RAG (Retrieval-Augmented Generation) project.

## Project structure

```
mini_RAG_ap/
├── assets/              # Assets
├── routes/              # Routes
├── tasks/               # Tasks
├── main.py
├── Dockerfile
├── docker-compose.yml
├── requirements.txt
├── .env.example
└── .gitignore
```

## Requirements

- Python 3.11
- Conda (Miniconda or Anaconda)

## Setup

```bash
conda create -n mini-rag python=3.11
conda activate mini-rag
```
